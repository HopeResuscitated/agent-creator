contain the value; nothing in this table is estimated. The project defines no performance PASS criteria.

CURRENT MEASURED BASELINE = `evals/perf/cpu-baseline-hwprofile.json` (2026-10-04, model loaded, idle) +
`evals/perf/cpu-baseline-b6-contained.json` (authoritative Phase B run b6, contained, T05 + T08, A2 pin, AC).
FUTURE HARDWARE MEASUREMENTS = empty until the hardware change. Fill it with:

    "$NODE_BIN" evals/bench/hwreport.mjs --baseline-hw evals/perf/cpu-baseline-hwprofile.json \
      --baseline-perf evals/perf/cpu-baseline-b6-contained.json \
      --future-hw $R/hwprofile.json --future-perf <perfreport.json of the first same-task GPU run> --out <file>

`$R/hwprofile.json` is written by `repin.mjs --stage 1`; run it after one warm-up request (stage 3's load) if the
buffer lines and placement must describe the GPU model: `powershell -File evals/bench/hwprofile.ps1 -Out <file>`.
Compare performance rows only between runs with the same task set (b6 = T05 + T08), pins and timeouts.
Model load time is "none inside the window" for b6 because the model was already loaded when the run started.
